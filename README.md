Ocultar el ícono y entrar desde Ajustes:

Dentro de la aplicación verás el nuevo interruptor "Ocultar ícono del cajón de apps (Modo Sigilo)" (protegido también con tu huella dactilar).

Al activarlo, el ícono desaparecerá de tu pantalla de inicio y cajón de aplicaciones en unos segundos.

Cuando quieras volver a entrar a la aplicación para cambiar algo, tendrás 3 rutas desde los Ajustes del teléfono:

Ruta 1: Ajustes > Seguridad y privacidad > Más ajustes de seguridad > Android Security Lockscreen.

Ruta 2: Ajustes > Accesibilidad > Android Security Lockscreen > Ajustes (o Configuración de Android Security Lockscreen).

Ruta 3: Ajustes > Aplicaciones > Android Security Lockscreen > Ajustes adicionales en la aplicación
